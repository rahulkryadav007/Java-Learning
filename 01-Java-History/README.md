# 1. Java History

## What is Java?

Java is a **high-level, class-based, object-oriented programming language** designed to be portable across different platforms.

Java follows the idea **"Write Once, Run Anywhere" (WORA)**. Java source code is compiled into **bytecode**, and bytecode runs on a Java Virtual Machine (JVM).

## Who created Java?

Java was originally developed at **Sun Microsystems** by a team led by **James Gosling** in the early 1990s.

The project was initially called **Oak**. It was later renamed **Java** and publicly released in **1995**.

## Why was Java created?

The original goal was to create a language suitable for portable software and consumer-electronic devices. Java later became especially popular for web applications, enterprise software, Android development, backend systems, and many other areas.

## Important Java milestones

| Year | Milestone |
|---|---|
| 1991 | Java project started at Sun Microsystems |
| 1995 | Java publicly released |
| 1996 | First major Java development kit releases and wider adoption |
| 2006 | Sun began releasing much of Java as open source |
| 2010 | Oracle acquired Sun Microsystems |
| Today | Java continues to evolve and is widely used in backend and enterprise development |

## Simple example

```java
class HelloJava {
    public static void main(String[] args) {

        // This is the main method.
        // Java starts program execution from here.
        System.out.println("Hello, Java!");
    }
}
```

### What happens?

1. You write Java source code in a `.java` file.
2. The Java compiler (`javac`) converts it into bytecode.
3. The bytecode is stored in a `.class` file.
4. The JVM loads and executes that bytecode.

## Key terms

- **Java** – the programming language and platform ecosystem.
- **Bytecode** – intermediate code generated by the Java compiler.
- **JVM** – the runtime that executes Java bytecode.
- **JDK** – the development kit used to develop Java programs.
- **WORA** – Write Once, Run Anywhere.
