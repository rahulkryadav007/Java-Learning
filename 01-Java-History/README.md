# 1. Java History

## What is Java?

Java is a **high-level, class-based, object-oriented programming language** and platform designed to build portable applications.

Java follows the idea **"Write Once, Run Anywhere" (WORA)**. Java source code is compiled into **bytecode**, and that bytecode is executed by the Java Virtual Machine (JVM).

> **Important:** Java is not the same thing as the JVM. Java is the language/platform ecosystem, while the JVM is the runtime that executes Java bytecode.

## Who created Java?

Java was originally developed at **Sun Microsystems** by a team led by **James Gosling** in the early 1990s.

The project started in **1991** and was initially called **Oak**. It was later renamed **Java** and publicly released in **1995**.

## Why was Java created?

The original project aimed to create portable software for consumer-electronic devices. Java later became widely used for:

- Web applications
- Enterprise applications
- Backend development
- Android development (historically and through the Java ecosystem)
- Desktop applications
- Distributed systems
- Cloud applications

## Why did Java become popular?

Java became popular because it provided:

1. **Platform independence** – bytecode can run on any platform with a compatible JVM.
2. **Object-oriented programming** – programs can be organized using classes and objects.
3. **Automatic memory management** – Java provides garbage collection.
4. **Strong standard library** – Java includes APIs for collections, I/O, networking, concurrency, and more.
5. **Security and robustness** – Java was designed with features that support reliable application development.
6. **Large ecosystem** – Java has a mature ecosystem, tools, frameworks, and community.

## Java Versions: What should beginners know?

You do **not** need to memorize every Java version.

For learning, understand the idea of **JDK versions** and know that Java has had important LTS releases such as Java 8, 11, 17, 21, and 25.

> **Note:** A Java version is commonly discussed as a JDK release, while the JVM is the runtime component used to execute Java bytecode.

## Simple example

```java
class HelloJava {
    public static void main(String[] args) {

        // This is the main method.
        // Program execution starts here for a normal Java application.
        System.out.println("Hello, Java!");
    }
}
```

### What happens when you run this program?

```text
HelloJava.java
     |
     | javac HelloJava.java
     v
HelloJava.class  -->  Bytecode
     |
     | JVM loads and executes bytecode
     v
   Output
```

Step by step:

1. You write Java source code in a `.java` file.
2. The Java compiler (`javac`) compiles the source code.
3. The compiler produces bytecode in a `.class` file.
4. The JVM loads and executes the bytecode.
5. The program produces the required output.

## Java Platform Components — Preview

You will study these in detail in the next module:

- **JDK (Java Development Kit)** – tools required to develop Java applications, including the compiler.
- **JRE (Java Runtime Environment)** – runtime components used to run Java applications; conceptually includes the JVM and supporting runtime libraries.
- **JVM (Java Virtual Machine)** – executes Java bytecode.

### Easy memory trick

**JDK → Develop**  
**JRE → Run**  
**JVM → Execute Bytecode**

## Key Terms

- **Java** – a programming language and platform ecosystem.
- **Oak** – the original name of the project that became Java.
- **Bytecode** – intermediate instructions generated by the Java compiler.
- **JVM** – runtime that executes Java bytecode.
- **JDK** – development kit containing Java development tools.
- **JRE** – runtime environment concept used to describe what is needed to run Java applications.
- **WORA** – Write Once, Run Anywhere.
- **OpenJDK** – open-source implementation/project for Java development.
- **Garbage Collection** – automatic memory management provided by the Java platform.

## Common Beginner Mistakes

### 1. Java = JVM ❌
Java and JVM are not the same.

### 2. Java code directly runs on the operating system ❌
Normally, Java source code is compiled to bytecode and the JVM executes that bytecode.

### 3. WORA means every Java program works everywhere without any conditions ❌
The target platform needs a compatible Java runtime/JVM and other platform-specific requirements may still matter.

### 4. Java was created in 1995 ❌
Development started earlier; **1995** is the year Java was publicly released.
