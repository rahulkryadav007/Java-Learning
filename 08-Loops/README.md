# 08 - Loops

Loops allow us to execute a block of code repeatedly.

## Loop Types in Java

1. `for` loop — best when the number of iterations is known.
2. `while` loop — best when repetition depends mainly on a condition.
3. `do-while` loop — executes the body at least once, then checks the condition.
4. Enhanced `for` loop (for-each) — used to traverse arrays and other iterable data.

## Supporting Loop Statements

- `break` — immediately terminates the loop.
- `continue` — skips the current iteration and moves to the next one.
- Nested loops — a loop inside another loop.

## Real-World Thinking

- `for`: process a fixed number of students.
- `while`: keep asking for a valid password until it is correct.
- `do-while`: show a menu at least once and repeat until the user exits.
- Enhanced `for`: read every value from an array.

## Practice Checklist

- Print numbers from 1 to 100.
- Print even and odd numbers separately.
- Find the sum of numbers from 1 to N.
- Reverse a number using a loop.
- Count digits in a number.
- Check whether a number is prime.
- Find factorial of a number.
- Print multiplication tables.
- Print patterns using nested loops.

## Common Mistakes

- Forgetting to update the loop variable.
- Using the wrong condition and creating an infinite loop.
- Confusing `break` with `continue`.
- Assuming `do-while` checks the condition before the first execution.
- Using an enhanced `for` loop when the index itself is required.
