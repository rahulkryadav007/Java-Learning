# 08 - Object-Oriented Programming (OOP)

Object-Oriented Programming is a way of designing programs using **objects** that contain data and behavior.

## Learning Order
1. Class & Object
2. Constructor
3. `this` keyword
4. `static`
5. Encapsulation
6. Inheritance
7. Method Overloading
8. Method Overriding
9. Polymorphism
10. Abstraction
11. Abstract Class
12. Interface
13. Multiple Inheritance using Interfaces
14. `final` keyword
15. Association, Aggregation & Composition

## Four Main Pillars
- **Encapsulation:** protect data and expose controlled methods.
- **Inheritance:** reuse/extend behavior from an existing class.
- **Polymorphism:** one interface/reference, different behavior.
- **Abstraction:** expose what an object does and hide implementation details.

## How to Study
Read each topic README first, run the example, then modify it yourself. Finally solve the interview questions without looking at the answer.

## Important Rule
OOP is not about memorizing definitions. Always ask: **What object am I modeling? What data belongs to it? What behavior belongs to it? What relationship does it have with other objects?**
