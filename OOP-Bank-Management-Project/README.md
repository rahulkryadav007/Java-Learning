# OOP Bank Management Project

Beginner-friendly Java project for understanding OOP using one simple Bank Management example.

## Concepts covered
- Class and Object
- Constructor
- `this` keyword
- Encapsulation
- Inheritance
- `super` keyword
- Method Overloading / Compile-time Polymorphism
- Method Overriding / Runtime Polymorphism
- Abstraction
- Interface

## Project flow
`BankAccount` is an abstract parent class. `SavingsAccount` extends it and implements the `Transaction` interface. `Main` creates objects and demonstrates the OOP concepts.

See `OOP_Bank_Project_Guide.pdf` for the complete beginner-friendly explanation.

## Run
```bash
javac *.java
java Main
```
